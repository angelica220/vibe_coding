# EMOTIONS IN FORM

Интерактивная визуальная лаборатория, которая преобразует эмоциональное состояние в уникальное абстрактное произведение.

---

## О проекте

EMOTIONS IN FORM — это генеративное веб-приложение, где пользовательские эмоции определяют визуальную композицию. Каждая эмоция имеет собственную геометрическую фигуру, которая влияет на форму, цвет и движение элементов на canvas.

## Основные возможности

### 12 эмоций с уникальной геометрией

Каждая эмоция отображается отдельной геометрической фигурой:

- **Спокойствие** — скруглённый квадрат
- **Тревога** — резкая многовершинная звезда
- **Вдохновение** — органическая клякса с волнистыми краями
- **Радость** — правильный круг
- **Восторг** — спираль с лучами
- **Любопытство** — разомкнутое кольцо с точкой у разрыва
- **Грусть** — асимметричная капля
- **Гнев** — многолучевая острая звезда
- **Надежда** — три вложенные дуги
- **Сомнение** — ломаная линия с разрывами
- **Усталость** — приплюснутый прямоугольник
- **Тоска** — два концентрических кольца

### 8 цветовых палитр

- Космическое свечение
- Янтарная вспышка
- Сапфировый импульс
- Контраст чувств
- Лавандовый туман
- Изумрудный сон
- Алый резонанс
- Монохромная тишина

### 6 форм композиции

- **Органика** — плавные, мягкие, неправильные формы
- **Геометрия** — круги, треугольники, многоугольники
- **Поток** — текучие волны, ленты, переплетения
- **Частицы** — светящиеся точки, абстрактные скопления
- **Нейронные связи** — пересекающиеся линии, узлы, соединения
- **Симметрия** — радиальный орнамент, зеркала, дуги, лучи

### Процесс создания

1. Выберите одну или несколько эмоций
2. Выберите цветовую палитру
3. Выберите форму композиции
4. Приложение создаст уникальную визуализацию, которую можно сохранить как изображение

## Технологии

- **HTML5** — структура приложения
- **CSS3** — стили, CSS-переменные, flexbox, grid, backdrop-filter (glassmorphism)
- **Vanilla JavaScript** — логика генерации, обработка событий
- **Canvas API** — рендеринг и анимация графики

## Структура проекта

```
├── index.html          # Главная страница (лендинг + генератор)
├── emotions.html       # Отдельная страница выбора эмоций
├── css/
│   └── style.css       # Основные стили проекта
├── js/
│   ├── main.recovered.js  # Основной файл: canvas-графика, эмоции, формы
│   └── emotions.js      # Логика выбора эмоций для emotions.html
└── images/             # Папка для изображений
```

## Запуск локально

Проект не требует сборки, сервера или установки зависимостей.

**Варианты запуска:**

- **Простой способ:** откройте файл `index.html` непосредственно в браузере.
- **Рекомендуемый способ:** запустите проект через расширение **Live Server** в VS Code.
